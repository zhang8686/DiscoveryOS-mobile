# DiscoveryX

一个面向 Android 手机的 4d4y（DiscoveryX）论坛客户端。全中文界面，一次只显示一层：帖子正文、帖子列表或版块；系统返回键与右滑逐级退出。

> 本项目为非官方客户端，与 4d4y.com、Comsenz / Discuz! 无关联。论坛内容与账号数据归论坛及其用户所有。

## 应用信息

- 包名：`com.mrky.discoveryos.mobile`
- 版本：V1.0.0（versionCode 27）
- 系统要求：Android 8.0+（minSdk 26 / targetSdk 35）
- 架构：arm64-v8a
- 权限：仅 `android.permission.INTERNET`

## 特色亮点

- **手机优先**：单栈页面层级，返回键/右滑逐级退出；版块栏可折叠，标题与搜索保持顺手。
- **论坛阅读**：正文、楼层、回复列表一体化；支持楼层跳转、收藏、编辑/删除自己的回复、查看网友资料卡。
- **图片与附件**：正文内嵌图片、附件下载；图片查看器支持多图横滑切换、扫码、保存到相册指引，黑底设计避免切换闪屏。
- **发帖与回帖**：支持图片/附件上传、本地草稿保存、引用回复；引用只显示作者与时间，可一键取消，正文与附件不受影响。
- **外链播放**：B 站、抖音、小红书等链接可在应用内解析播放，其他链接交给系统浏览器。
- **界面外观**：多套主题（含温暖米色），字号与头像大小随设置等比适配。
- **流畅体验**：请求超时重试与优先级调度、头像提前预取、列表行高稳定，弱网下首屏内容更快呈现。

## 源码来源

本项目为 NSH（TSX）应用，构建环境为 NSH 0.5.1、JDK 17、Android SDK 35。入口为 `App.tsx`，论坛逻辑在 `src/discuz/`，界面在 `src/ui/`，网络策略在 `src/net/`。
